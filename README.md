## 🌟 Особенности

### 📈 **Визуализация в реальном времени**
- **Интуитивная панель наблюдения за параметрами** с мгновенным отображением параметров
- **Регулировка уставок** давления и уровня воды 
- **4 типа графиков** с фиксированными осями для удобства анализа
- **Температурные профили** (вода/топка) 0-400°C
- **Динамика давления** 0-1100 кПа
- **Баланс массы воды** 0-4000 кг
- **Сравнение фактического и измеренного давления**

### 🔬 **Реалистичное моделирование**
- **Физически точная модель** парового котла
- **Термодинамические расчеты** на основе уравнений состояния
- **Реалистичные параметры** промышленного оборудования
- **Корректные зависимости** температура-давление пара
- **Автоматические ПИ-регуляторы** для поддержания заданных параметров

## 🛠 Технологии

| Компонент | Технология |
|-----------|------------|
| **Backend** | Python 3.8+, Django 4.0+ |
| **Frontend** | HTML5, Bootstrap 5, Chart.js |
| **Моделирование** | NumPy, SciPy |
| **Реальное время** | Threading, AJAX |
| **Визуализация** | Canvas API, Responsive Design |

### ⚡ **Потоки выполнения**
- **Основной поток**: Django сервер
- **Фоновый поток**: Моделирование котла (0.05 сек шаг)  
- **AJAX запросы**: Обновление интерфейса (3 сек интервал)

## 🔧 API Endpoints

| Метод | Endpoint | Назначение |
|-------|----------|------------|
| `GET` | `/api/current-data/` | Текущие параметры котла |
| `GET` | `/api/chart-data/` | Данные для графиков |
| `POST` | `/api/update-setpoint/` | Изменение уставок |

## ⚙️ Установка и запуск

**Требования:**
- Python 3.8 или выше
- Django 4.0+
- Установленные пакеты: NumPy, SciPy

```bash
# Клонирование репозитория
git clone https://github.com/your-username/boiler-monitor-system.git
cd boiler-monitor-system

# Установка необходимых библиотек
pip install django numpy scipy

# Запуск сервера
python manage.py runserver
